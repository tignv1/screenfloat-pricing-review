## ScreenFloat 解决的是哪类麻烦

macOS 自带的那套截图快捷键（Shift+Cmd+4 之类）把图片存成文件，你还得打开预览、再切回来。ScreenFloat 把这一步省掉：按下快捷键框选区域，截下来的图立刻变成浮窗，贴在所有窗口上方，切到别的 Space 或者进全屏应用它还在。

开发商已经做了十二年多，从最早的浮窗截图工具做到现在这个规模，浮窗始终是它的核心。安装包只有 16.7 MB，装上不占地方。

浮窗之外还有一批功能。用起来频率不算高，但真需要的时候很省事。

- Shots Browser：截图库，支持文件夹、标签和搜索，几年前的截图也能翻出来
- OCR：识别图里的文字，双击就能复制识别出的邮箱、电话、链接
- 录屏和剪辑：录完能裁、能转、能静音，也能直接导出 GIF
- 标注与打码：线条颜色粗细都能调，非破坏性，随时改回来
- 取色和条码：Option 加右键拖拽取色；右键点条码能看内容、复制或者遮掉

一条条列出来像产品说明书，实际用起来最值钱的是前两条。浮窗解决“看一眼”，Shots Browser 加 OCR 解决“找回来”和“抄下来”。剩下的功能，市面上的截图工具多少都有一些，不构成非它不可的理由。

## 真实评价与几个要提前知道的缺点

MacUpdate 上关于 ScreenFloat 的评价有 20 条上下，数量不算多，这款软件的用户群本来就窄。英文的测评汇总里，被反复夸的是浮窗、Shots Browser 和 OCR，被反复提到的意见只有一个，浮窗开多了会挡视线。

这个抱怨是真的。解决办法有两个，都是软件自带的。滚轮上下滑可以调整浮窗透明度；也可以设一个双击动作，让浮窗降低透明度并且忽略鼠标点击，它就变成一层看得见但点不到的背景。花五分钟配好，这个缺点基本消失；不配，它每天都会烦你一次。

其他要提前知道的：

- 只支持 macOS 12.3 及以上，系统太老装不上
- 跨 Mac 同步截图库要登录一个免费的 iCloud 账户
- 中文界面是官方自带的，简体中文和英语、德语、荷兰语并列在支持列表里，但中文教程很少，遇到问题基本得看英文文档
